# TradePlaybook AI 产品说明

## 产品定位

TradePlaybook AI 是一个个人 AI 交易辅助系统，不是自动交易系统，不是量化交易机器人，也不是喊单系统。

产品核心是：AI 帮用户建立并执行自己的交易体系。符合用户交易体系才生成交易计划，违反体系就阻止交易。

## MVP 目标

第一阶段只验证最小产品骨架和工作台方向：

1. 使用 mock 数据展示 AI 交易工作台。
2. 使用共享类型约束前后端数据结构。
3. 提供最简单的 HTTP API。
4. 不接真实 AI、不接真实交易所、不接真实数据库。
5. 所有交易相关文案强调用户最终确认。

## 核心流程

1. 用户维护自己的交易体系、风险规则和禁止事项。
2. 用户提出交易想法。
3. 系统按用户体系审核交易想法。
4. 绿灯或黄灯状态下，系统可以生成 mock 交易计划，并要求用户最终确认。
5. 红灯状态下，系统必须阻止生成执行计划。
6. 交易结束后，用户记录和复盘，沉淀规则。

## 第一版页面

前端第一版页面是 AI 交易工作台：

1. 左侧：mock 图表和关键价位标注。
2. 右侧：AI 对话和纪律审核结果。
3. 下方：交易体系、候选计划和风险规则数据面板。
